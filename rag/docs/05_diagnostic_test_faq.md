# Diagnostic Test FAQ

> **Demo FAQ for the Medbot RAG knowledge base.** Replace example
> answers with verified content before using the application with real
> patients.

## What does the Medbot help with?

Medbot answers questions about diagnostic-test preparation and can help
initiate specialized diagnostic-test scheduling.

## Where does preparation information come from?

Preparation information should come from the indexed knowledge-base
documents and approved diagnostic-center protocols. The LLM should use
retrieved information instead of inventing clinical instructions.

## Does every blood test require fasting?

No general assumption should be made. Fasting requirements depend on the
specific test and the applicable laboratory protocol.

## Can Medbot decide whether a patient is medically fit for a test?

No. The assistant should not independently provide medical clearance. If
retrieved information identifies a possible safety concern, the patient
should be directed to the appropriate clinical team.

## Can Medbot check insurance coverage?

The RAG knowledge base can explain insurance-verification requirements.
Actual coverage should be obtained from an authorized insurance or
laboratory system when such an API is available.

## Does the LLM receive the patient's insurance number?

No. The project guidelines specify that the National Health ID /
Insurance Member Number is kept outside the main LLM prompt context.

## How is the diagnostic center selected?

The frontend provides a dropdown containing the supported
diagnostic-center choices. The selected center is handled as an
application input rather than being generated by the LLM.

## How is an appointment booked?

The booking operation is handled by the external appointment-scheduling
API. The assistant gathers the required information and then hands the
booking operation to the external tool.
